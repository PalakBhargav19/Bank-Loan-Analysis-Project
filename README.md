# 📊 Bank Loan Analysis Dashboard

## 📌 Project Overview

This project focuses on analyzing bank loan data to understand loan applications, approval status, customer financial profiles, credit scores, income, loan amounts, and other key factors affecting loan outcomes.

The project combines **Excel/CSV, Python, and Power BI** to perform data analysis and create an interactive **Bank Loan Analysis Dashboard**.

## 🎯 Objectives

* Analyze loan application and approval trends
* Understand customer income and credit score patterns
* Compare approved and rejected loans
* Analyze loan amounts and customer financial information
* Identify important patterns and insights from the dataset
* Build an interactive and professional Power BI dashboard

## 🛠️ Tools & Technologies

* **Excel / CSV** – Dataset
* **Python** – Data Cleaning & Analysis
* **Pandas & NumPy** – Data Processing
* **Matplotlib** – Data Visualization
* **Power BI** – Interactive Dashboard
* **Jupyter Notebook** – Python Analysis
